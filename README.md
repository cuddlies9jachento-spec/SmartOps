\# SmartOps



智能设备监测与运维管理系统



\## 项目简介



SmartOps 是一个基于 Qt/C++ 开发的智能设备监测与运维管理系统。



系统通过虚拟串口和 DeviceSimulator 模拟真实设备，实现：



\- 串口通信

\- 设备数据采集

\- 自定义通信协议

\- 实时状态监控

\- 异常告警

\- 工单管理

\- 历史数据分析

\- 操作日志

\- AI 辅助问答与故障总结



\## 技术栈



\- C++17

\- Qt 6

\- Qt Serial Port

\- MySQL

\- Git

\- AI API
